# Alice AI Assistant — OpenAI + optional Serper

Приватный голосовой навык Яндекс Алисы с ответами OpenAI. Сервер: Vercel. Поиск Serper необязателен.

## Переменные Vercel
- `OPENAI_API_KEY` — обязательный секретный API-ключ OpenAI (не ключ от подписки ChatGPT).
- `OPENAI_MODEL` — необязательно, по умолчанию `gpt-5-mini`.
- `SERPER_API_KEY` — необязательно, поиск по актуальным вопросам.

Никогда не сохраняйте ключи в GitHub или переписке.

## Развёртывание
1. Импортируйте репозиторий в Vercel как проект Node.js.
2. В Settings → Environment Variables добавьте `OPENAI_API_KEY` для Production и, по желанию, `SERPER_API_KEY`.
3. Выполните Deploy/Redeploy. Проверьте `https://ВАШ-ДОМЕН.vercel.app/api`: должен вернуться JSON с `ok: true`.
4. В Яндекс Диалогах создайте навык с HTTPS webhook `https://ВАШ-ДОМЕН.vercel.app/api`, включите хранение данных в навыке и выберите приватный режим.
5. Проверьте навык в тестере Диалогов, затем запустите на Яндекс Станции с тем же аккаунтом.

## Проверки
`npm test` — автоматические тесты. Живые ответы требуют рабочего OpenAI API-ключа и оплаченного API-баланса.

## Ограничения
Время на ответ Алисе ограничено: при медленной сети или поиске навык может вернуть сообщение о повторной попытке. Поиск Serper используется только при запросах, похожих на запрос актуальных данных. Если ключ поиска отсутствует, обычные вопросы работают без него.
